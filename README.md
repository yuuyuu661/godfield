# 32チーム・トーナメント v1.5
## ルーレット：削除タイミングの挙動変更
- 「SPIN!（出目を削除）」は、**今回の出目を「次回このボタンを押した時」に削除**する方式に変更。
- 画面下部に「次回削除予定: XXX」を表示（いつ消えるかが明確）。
- 通常の「SPIN!」は影響なし。

その他:
- 針と結果の一致、効果音、32プリセットはそのまま。
- 効果音は `public/sfx/spin.mp3` / `public/sfx/stop.mp3` を配置してください。

## 起動
```bash
cp .env.example .env
npm install
npm start
```
