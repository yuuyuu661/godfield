# 可変トーナメントメーカー

12〜32人のトーナメント表を自動作成し、ルーレットでプレイヤーを各シード枠へ割り当てるWebアプリです。シングルエリミネーションとダブルエリミネーションに対応しています。

## 起動

1. Node.js 18以上をインストールします。
2. このフォルダで npm install を実行します。
3. npm start を実行します。
4. ブラウザで http://localhost:3000 を開きます。

## 操作

- 参加人数を12〜32人で入力すると、16枠または32枠の表とBYEが自動生成されます。2敗で敗退する大会では、作成時に「ダブルエリミネーション」にチェックを入れます。
- プレイヤー名を半角カンマ、読点、または改行で区切って一括登録できます。
- 登録先のシードを選び「回す」を押すと、当選者が表へ入り、ルーレット候補から削除されます。
- 対戦カードの名前を押すと勝者を登録できます。BYEは自動で勝ち上がり、不戦勝から敗者は発生しません。
- ダブル形式では、勝者トーナメントで負けた選手が下の敗者トーナメントへ自動で移ります。敗者トーナメントで負けると敗退です。
- グランドファイナルは両トーナメントの代表が対戦します。勝者側代表が第1試合に勝てば優勝です。敗者側代表が勝つと両者が1敗になるため、第2試合で優勝者を決めます。
- 勝者を訂正した場合は、対戦者が変わる後続試合の結果が取り消されます。
- 上部のリセットには、起動環境の `ADMIN_PASSWORD` に設定したパスワードが必要です。

本番環境とローカル環境のどちらでも、`ADMIN_PASSWORD` が未設定の場合はリセットできません。すでに `ADMIN_PASSWORD` を設定している環境では、その設定を引き続き使えます。

## テスト

`npm test` で、12〜32人の勝ち上がり、不戦勝、決勝リセット、結果訂正、旧データとの互換性を確認できます。
