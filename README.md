# 可変トーナメントメーカー

12〜32人のシングルエリミネーション表を自動作成し、ルーレットでプレイヤーを各シード枠へ割り当てるWebアプリです。

## 起動

1. Node.js 18以上をインストールします。
2. このフォルダで npm install を実行します。
3. npm start を実行します。
4. ブラウザで http://localhost:3000 を開きます。

## 操作

- 参加人数を12〜32人で入力すると、16枠または32枠の表とBYEが自動生成されます。
- プレイヤー名を半角カンマ、読点、または改行で区切って一括登録できます。
- 登録先のシードを選び「回す」を押すと、当選者が表へ入り、ルーレット候補から削除されます。
- 対戦カードの名前を押すと勝者を登録できます。BYEは自動で勝ち上がります。
- 上部のリセットボタンは管理者パスワード gerogero が必要です。

本番環境では、環境変数 ADMIN_PASSWORD を設定すると管理者パスワードを変更できます。
